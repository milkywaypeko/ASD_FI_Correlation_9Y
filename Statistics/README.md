# 원본 통계자료 폴더 안내 (2014–2022)

이 폴더는 **원본 데이터를 주제별로 정리**합니다. 파일 값은 임의로 보정하지 않으며,
회귀에 사용하는 단위 변환·지역명 정규화·결측 필터는 Python 빌드 코드에 기록됩니다.

```text
Statistics/
├─ 인구/
│  ├─ Resident population.csv                 # 장애인 등록률 분모
│  ├─ 연령(5세)별 주민등록연앙인구.csv            # 0–14세, 65세 이상 비율
│  ├─ 행정구역(시군구)별 주민등록세대수.csv   # [동봉] 2014~2022년 실제 지역별 세대수
│├─ 장애인등록/Disability/                     # 17개 시도별 원자료
├─ 재정/Financial Independence.csv            # 재정자립도
├─ 출산율/Birth rate.csv                      # 합계출산율
└─ 국가건강정보/
   ├─ 진료비/시군구(...)별 연령별 진료현황-전체.csv  # 4개, 인구 1인당 진료비에 사용
   └─ 보험료/시군구(...)별 보험료 현황.csv          # 4개, 건강보험료 총액에 사용
```

## 건강보험료 가구당 환산

선택된 건강보험료 데이터는 **연도별 보험료 총액(단위: 천 원)**이며,
`합계 = 직장 소계 + 지역 소계` 및 `직장 소계 = 근로자 + 공·교`가 맞는 값만 사용합니다.

```
연간 가구당 건강보험료(만원/세대) = 연간 보험료 총액(천원) ÷ 주민등록세대수 ÷ 10
```

이는 **지역 전체 보험료를 등록 세대수로 나눈 환산 금액**입니다.
보험 가입 가구별 실제 납부보험료의 평균, 개인 부담액 또는 월평균 보험료가 아닙니다.
직장 보험료에 사용자 부담 등이 포함될 수 있으므로 해석에 주의해야 합니다.

- 행정안전부 주민등록 인구통계의 연도별·시군구별 `세대수` 원본을
  `인구/행정구역(시군구)별 주민등록세대수.csv`에 **이미 포함**했습니다.
  시 합계 아래 중복된 하위 구 행은 시 전체와 중복 계산하지 않습니다.
- 널리 호환되는 입력 형식은 `연도,시도,시군구,세대수`이며, 2014~2022년 전 기간을 지원합니다.
  파일은 UTF-8-sig·CP949·EUC-KR을 읽을 수 있습니다.
- 단일 지역열 + `2014,...,2022` 형태의 세로 지역/가로 연도 CSV,
  시도/시군구 2개 지역열이 있는 가로형 CSV도 지원합니다.
- 실제 세대수를 찾지 못한 관측치는 보간하지 않습니다.
  다른 지표(인구수, 진료인원수, 평균 가구원수)로 임의 대체하지도 않습니다.
- **2014년 서울·인천·경기·강원 보험료 CSV**에는 다른 통계로 보이는 값이 섞여
  보험료 집계 항목 간 정합성이 맞지 않습니다. 해당 2014년 관측치는 회귀에서 제외합니다.
  원본 CSV는 삭제하거나 수정하지 않고 결측 감사에 기록합니다.

출처별 기초단위 차이(세종·제주 예외, 시의 구 집계, 2014년 경기도 청각·언어 통합 유형 등)는
대시보드의 데이터 품질 보고서와 `site/data/age_medical_quality.json`에서 확인합니다.

행정안전부 세대수 공식 출처: https://jumin.mois.go.kr/

특히 서울·인천·경기·강원 2014년 원본 보험료 항목 불일치는
다른 연도에 임의 복제하지 않습니다. 다른 지역의 2014년 보험료 값도
**회귀에서는 전부 사용하지 않습니다.**

장애유형은 전체, 지체, 뇌병변, 시각, 청각, 언어, 청각·언어, 지적,
자폐성, 정신, 신장, 심장, 호흡기, 간, 안면, 장루·요루, 뇌전증을 지원합니다.
경기도 2014~2017년의 청각·언어 통합 유형은 원자료 집계 방식대로
별도로 유지하고, 청각 또는 언어 유형에 분배하지 않습니다.

**결측 규칙:** 결측·비수치·유효하지 않은 분모는 NaN/None으로
관리하며 0 또는 임의 보간값으로 바꾸지 않습니다. 모델별로
종속변수 및 모든 설명변수가 존재하는 완전관측치만 OLS에 사용합니다.
연도·지자체·유형에 따라 달라지는 표본 수는 경량 회귀 인덱스에
각각 `n`으로 기록합니다. 상수 설명변수·완전 공선성·표본 부족은
경고 사유를 기록합니다. 역사적 행정구역 개편, 시군구/시도 단위,
중복 하위 구와 집계 기준 차이를 처리하며, 이는 측정오차 또는
관측 누락 가능성을 완전히 제거하지 않습니다.

**해석 경계:** 진료비는 지역 총진료비의 인구당 환산액이지
개인별 실제 본인부담금 또는 비급여 전체가 아닙니다.
건강보험료는 **1인당이 아닌 세대당** 금액이며 지자체 총보험료를
주민등록세대수로 나눈 환산액입니다. 개별 가입 세대에 실제
고지된 보험료의 산술평균이라고 해석해서는 안 됩니다.
모든 통계적 연관성은 인과관계를 증명하지 않습니다.

이번 17개 CSV의 **KOSIS 시도별 기본통계 표는 과거 [ASD_FI_Correlation](https://github.com/milkywaypeko/ASD_FI_Correlation)에서 사용한 원표와 동일**합니다. 이전 연구에는 2016·2019·2020년 등 시도별 특정 연도만 정리돼 있었지만 본 연구는 **2014~2022년** 연도 열을 사용합니다. 17개 시도의 개별 원본 URL 및 표 ID는 [KOSIS 출처 등록부](../KOSIS_SOURCES.md)에 재수록했습니다. 서울 종로구(2019, 지체 2,661명), 인천 중구(2016, 지체 2,912명), 경기 수원시(2019, 지체 20,258명), 부산 중구(2020, 지체 1,173명)의 값이 기존 단일연도 파일과 다년 파일에서 일치함을 대조했습니다. **전체 지자체·장애유형 값을 전수 검증했다는 뜻은 아닙니다.**


## 요양기관 종별 기관 수 (인구 10만 명당 분석용 추가자료)

출처: 국민건강보험공단·건강보험심사평가원, 「건강보험통계」, 2026 2/4, 2026.11.11, 「시군구별 종별 요양기관 현황」. [KOSIS 원표 DT_HIRA4B](https://kosis.kr/statHtml/statHtml.do?orgId=354&tblId=DT_HIRA4B&conn_path=I2).
