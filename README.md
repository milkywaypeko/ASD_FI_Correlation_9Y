# 장애인 등록률 통합 OLS 대시보드 (2014–2022)

> **전체 프로젝트를 GitHub 저장소 루트에 그대로 올릴 수 있습니다.** 최상위 `index.html`과 `.nojekyll`이 자동 생성됩니다. GitHub Pages를 `main / (root)`로 설정하세요. `site/index.html`은 독립적으로도 동작합니다.

**정적 분석 웹페이지:** `site/index.html`(장애유형×재정자립도), `site/results.html`(회귀 통합), `site/multivariate.html`(재정자립도 + 출산율 → **선택 장애유형 등록률** 다중회귀), **`site/birth-ols.html`(출산율 → **선택 장애유형 등록률** 단순 OLS)**, **`site/fiscal-birth.html`(재정자립도 → 출산율 단순 OLS)**, `site/quality.html`(품질). 프로젝트 최상위 `index.html`에서도 메인 대시보드가 직접 표시됩니다. 모든 하위 페이지는 `site/`의 파일을 참조합니다.

## 2D 시각화 유지

다중회귀 분석 화면은 **실제 장애인 등록률을 표시하는 2D 산점도 2개**와 조건부 예측선, 계수·p-값 추이 및 회귀결과 비교표로 구성합니다. **3D 산점도·회귀평면과 Plotly 의존성은 사용하지 않습니다.** 독립변수가 향후 추가되더라도 산점도는 각 독립변수별로 확장할 수 있습니다. 회귀모형 계산, 관측치, `statsmodels` Raw 결과는 변경하지 않았습니다.

`./Statistics` 디렉터리의 주민등록인구·재정자립도·장애인 등록현황 CSV를 이용해 `statsmodels.OLS`를 수행하고 **GitHub Pages용 정적 웹사이트**를 출력하는 Python 프로젝트입니다. 기존 원자료에 진료비 4개·보험료 4개·연령대별 인구·주민등록세대수를 더해 주제별로 정리했습니다. 원본 파일은 변경하지 않습니다.


## 2026년 10월 추가 수정: 메인 회귀결과 비교와 실제 등록률 그래프

1. `site/index.html` 및 GitHub 저장소 루트의 `index.html`에 **재정자립도 × 장애유형별 등록률** 회귀 결과 비교표를 추가했습니다. 기존 다중회귀 페이지의 「모든 장애유형 결과 함께 비교」와 「모든 광역지자체 결과 포함」에 해당하는 필터를 지원하며, 연도 슬라이더/9개년 통합/개별 기초 시계열과 연동됩니다. 표를 선택하면 해당 통계모형의 `statsmodels.OLS(...).fit().summary()` Raw 출력과 **그 모형에 사용된 실제 등록률 관측치**(표 최대 50개, 전체 CSV 저장)를 보여줍니다. 기존 `results.html`도 유지합니다.
2. `site/multivariate.html`의 **두 산점도 Y축은 실제 관측된 장애인 등록률(%)**입니다. 기존의 `Y - β(다른 변수 - 평균)` 보정등록률 계산을 표시 데이터에서 제거했습니다. 주황색 회귀선은 다중회귀의 두 독립변수 중 **다른 독립변수를 현재 선택한 표본의 평균으로 고정한 조건부 예측선**입니다. 점들은 실제 관측값이고 조건부 예측선 자체가 두 점 축 사이의 단순회귀선은 아닙니다. 원문의 statsmodels 다중회귀 계수나 재정자립도 정규화 연산은 변경하지 않았습니다.
3. 데이터셋은 프로젝트 빌드에서만 재정자립도 0~100을 0~1로 변환합니다. CSV 파일의 원본 값은 변경하지 않습니다.

## 실행하기

```bash
cd disability-fiscal-dashboard
python -m pip install -r requirements.txt
python build.py
python -m http.server 8000  # 프로젝트 최상위에서 실행
```

브라우저에서 `http://localhost:8000`(최상위 `index.html`) 또는 `http://localhost:8000/site/birth-ols.html`(장애유형 단순회귀), `http://localhost:8000/site/fiscal-birth.html`(재정자립도×출산율 단순회귀)를 엽니다. 재현 실행 시 기존 `site/data/`와 `site/raw/`의 계산 결과를 덮어씁니다. 다른 경로를 쓰려면:

```bash
python build.py --input /path/to/project --output /path/to/public
```

`--input` 아래에 `Statistics/출산율/Birth rate.csv`, `Statistics/재정/Financial Independence.csv`, `Statistics/인구/Resident population.csv`, `Statistics/장애인등록/Disability/Population of the disabled in *.csv`가 있어야 합니다. 다른 시도 파일을 추가할 경우 `build.py`의 `FILE_TO_PROVINCE` 항목에 등록하세요.

## GitHub Pages 배포 — 프로젝트 전체 업로드

1. `python -m pip install -r requirements.txt` 및 `python build.py`를 먼저 실행해 분석 데이터를 생성합니다. **원본 Statistics CSV는 수정하지 않습니다.**
2. 저장소 최상위에 프로젝트 전체(`index.html`, `.nojekyll`, `build.py`, `Statistics/`, `site/` 등)를 업로드합니다. **`site/`를 별도로 루트로 옮기거나 HTML 경로를 수정할 필요가 없습니다.**
3. GitHub 저장소의 `Settings → Pages → Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
4. `https://사용자명.github.io/저장소명/`에서 메인 페이지가 표시되고, 사이드 메뉴에서 출산율 단순회귀·다중회귀 등으로 이동합니다.

최상위 `index.html`은 `site/index.html`에서 생성한 **실제 대시보드 HTML**입니다. `<base href="./site/">`를 사용해 상대 URL·JS fetch가 `site/` 아래 파일을 가리키게 합니다. 최상위 `.nojekyll`도 자동 생성합니다. `site/` 안의 HTML 파일은 별도 base 없이 직접 접근 가능합니다. `--output`을 사용자 지정 폴더로 지정한 경우 해당 폴더 자체가 완성된 배포용 웹사이트입니다.

> GitHub Pages에서 Python 코드는 실행되지 않습니다. CSV를 수정하면 **로컬에서 `python build.py`를 다시 실행한 후** 생성된 `index.html` 및 `site/data/`, `site/raw/` 등의 변경 파일을 저장소에 반영해야 합니다. Chart.js는 CDN 사용으로 차트 표시 시 인터넷 연결이 필요합니다.

## 기능

- **메인 대시보드:** 회귀 단위(기초 간·광역 간·개별 기초 시계열), 광역 필터, 기초 필터, 장애유형, 재정자립도 개편 전후, 단일 연도 슬라이더, 9개년 통합 선택. 산점도 툴팁에 광역·기초 지자체명 및 연도·수치를 표시합니다. 회귀선, 기울기, 절편, R², p-값과 표본 수가 그래프 위 카드에 나타납니다. 각 연도별 4개 계수 추이도 제공합니다. **이제 메인 페이지에서도** 시점·광역·기초지자체별 OLS 통계표, 「모든 장애유형 함께 비교」, 「모든 광역지자체 결과 포함」 체크박스, 회귀 결과 CSV, 선택 행의 statsmodels Raw 및 **선택 모형의 실제 등록률·예측값·잔차 관측치와 별도 CSV**를 지원합니다. 원자료 표 필터·페이지 넘김·CSV 내려받기와 현재 모형 statsmodels 원문도 유지합니다.
- **통합 결과:** 개별 연도×전국/광역 필터로 산출한 모형 목록, 단위·유형·개편 전후·지역별 검색 및 정렬, 4개 계수 시계열 그래프, 각 모델 원문과 산점도 연결, CSV 내보내기. 기초지자체 9개년 시계열 모형도 조회할 수 있습니다.
- **출산율 × 장애유형별 단순 OLS:** `birth-ols.html`에서는 **전체·지체·뇌병변·시각·청각·언어·청각·언어(통합)·지적·자폐성·정신·신장·심장·호흡기·간·안면·장루·요루·뇌전증** 중 하나를 선택해 `선택 장애유형 등록률(%) = β₀ + β₁ × 합계출산율`을 적합합니다. 자폐성이 초기값이며 다른 유형으로 선택을 바꾸면 산점도/회귀식/통계카드/연도별 그래프/관측치/Raw 출력이 함께 바뀝니다. 연도 슬라이더(2014~2022), 전체 기간 통합, 전국/광역/기초 시계열을 지원합니다. 표의 `모든 장애유형 결과 함께 비교`를 선택하면 서로 다른 유형의 OLS 통계도 한 표와 CSV에서 확인할 수 있습니다. **이 단순 OLS에는 재정자립도가 포함되지 않습니다.**
- **장애유형별 다중선형회귀:** `multivariate.html`에서 동일한 모든 장애유형을 종속변수로 선택하고 `선택 장애유형 등록률(%) = β₀ + β₁ × 재정자립도(0~1) + β₂ × 합계출산율`을 적합합니다. 재정자립도 개편 전/후, 지역/연도 선택, 두 개의 실제 등록률 산점도(다른 독립변수를 표본 평균으로 고정한 다중회귀 조건부 예측선 표시), 두 계수와 각각의 p-값, R²/수정 R², 95% 신뢰구간, 6개 연도별 추이, 관측치 CSV, 유형별 Raw 출력과 모든 유형 비교표를 제공합니다.
- **공통 처리:** `Statistics/`에 있는 CSV는 모두 원본 그대로 유지합니다. 재정자립도 백분율은 `build.py` 안에서 100으로 나누어 사용하며, 선택된 유형이 원본에서 비어 있으면 회귀 표본에서 제외합니다. **경기도 2014~2017 `청각·언어`는 통합 유형**으로만 취급하므로 전국 연도별 `청각`/`언어`의 표본 수가 줄 수 있고, 통합 유형은 경기도 이외 지역의 회귀가 불가능합니다. 무작위 결측 대체나 합성 분리 없이 경고를 저장합니다.
- **데이터 품질:** 지자체 및 장애유형 정규화 방법, 조인 검사, 부적합 행 처리, 분석 가정을 기록합니다.

## 장애인 등록률과 지역 매칭

```
유형별 장애인 등록률(%) = 해당 유형 장애등록인원 ÷ 해당 연도 주민등록인구 × 100
전체 장애인 등록률(%) = 합계(장애유형별 등록인원) ÷ 주민등록인구 × 100
```

- 지역명은 **(연도, 광역지자체, 기초지자체)** 키를 이용하며, 동일 이름인 `중구`, `서구`, `남구` 등은 서로 다른 광역의 자료와 섞이지 않습니다.
- 장애유형 이름 끝의 `장애`를 제거하고 `장루, 요루`, `장루요루`, `장루·요루`를 통일합니다. `'기타'`는 원본 데이터가 빈 칸인 비공식 유형이라 표준 15유형에서 제외합니다.
- 경기도의 **2014~2017년 `청각·언어` 통합항목은 별개의 항목**입니다. 개별 `청각`, `언어`의 과거 값으로 복제하지 않으며, 전체 인원 합계에는 한 번만 포함합니다. 시도별 유형별 등록률을 비교할 때 통합/분리 구간에 유의하세요.
- 충북은 **2014년 청주시 통합 인구·장애등록인원을 사용**합니다. 재정 원본에서 이름이 ‘충북 청주시’로 적힌 2014년 값을 해당 통합 청주시의 재정자립도로 결합합니다. 재정자료의 당시 ‘충북 청원군’ 항목은 2014년 주민등록인구·장애등록인원 자료가 없으므로 분석에서 제외합니다. 인천 `남구 → 미추홀구`, 강원 `강원도 → 강원특별자치도`, 전북 `전라북도 → 전북특별자치도`로 표준화합니다. 대구 편입 이전인 **군위군 2014~2022년은 경북 관측치**만 사용합니다.
- **세종·제주를 광역 하나이자 기초 하나**로 처리합니다. 제주 주민등록인구는 `제주시`·`서귀포시`를 합산하지 않고 **제주특별자치도 공식 합계**를 사용합니다. 이 두 곳은 예외적 행정단위임을 설명합니다.
- 광역 시도 등록인원은 하위 분석대상 기초단위 등록인원 합계, 광역 주민등록인구는 그 해의 시도 공식 합계, 광역 재정자립도는 시도 공식 소계입니다. 기초 시계열과 광역 시계열은 완전히 다른 분석 단위입니다.
- **결측치 처리:** 원자료 빈 문자열·`-`는 결측 처리. 회귀분석에는 X와 Y 모두 존재하는 관측치만 포함하며 보간하거나 0으로 바꾸지 않습니다. 일부 지자체·연도에서 매우 드문 장애유형의 원본 수치가 비어 있으므로 `전체` 유형의 인원 합계는 **수치가 제공된 유형들의 합**이며 실제보다 소폭 작을 수 있습니다. 해당 지역·연도와 공란 유형을 `quality.json`의 `partially_reported_types`에 저장하고, 산점도 툴팁과 데이터 품질 페이지에서 확인할 수 있습니다.

## 회귀모형의 정의 및 한계

`statsmodels.api.OLS(Y, add_constant(X)).fit()`을 이용하여 장애인 등록률 Y(%)와 정규화된 재정자립도 X(0~1)의 **단순 선형회귀(절편 포함)** 를 계산합니다. 모형별 `n`, 기울기 `β₁`, 절편 `β₀`, 결정계수 `R²`, 기울기 양측 p-값, `fit().summary()` Raw 문자열을 JSON 및 원문 텍스트에 저장합니다. 표본이 3개 미만이거나 X 분산이 0이면 계수를 계산하지 않고 사유를 저장합니다.

- 단일 연도 + 기초 단위 = 그 해의 전국 또는 특정 광역 산하 기초지자체 간 회귀.
- 단일 연도 + 광역 단위 = 그 해 전국 17개 광역지자체 간 회귀.
- 전체 연도 통합 + 기초 단위 = (기초지자체, 연도) 관측치를 합쳐 회귀.
- 전체 연도 통합 + 광역 단위 = (광역지자체, 연도) 관측치를 합쳐 회귀.
- 개별 기초지자체 시계열 = 해당 단위의 2014~2022 9개 데이터로 회귀.

**주의:** 연도 통합 분석에서 각 지자체의 연도별 관측치는 독립적이지 않을 수 있습니다. 인구 구조/장애등록 기준 변화/재정 정책 등 공변량을 통제하지 않았으므로 계수와 p-값을 인과관계나 정책효과로 해석해서는 안 됩니다. 소수 표본(세종·제주)은 당해년도 기초 간 횡단면 회귀를 구할 수 없으므로 기초지자체별 시계열 분석을 사용하세요. 장애인 등록률은 전체 인구 대비 등록률이며 등록인원 구성비와 다릅니다.

## 2026 추가 기능: 재정자립도 0~1 정규화 + 자폐성 장애 다중회귀

**원본 `Statistics/재정/Financial Independence.csv`는 변경하지 않습니다.** `build.py`의 `parse_fiscal` 함수에서 CSV 수치가 읽힌 뒤 메모리상으로 `원본값 / 100`을 적용합니다. 예: 47.51(%) → 0.4751. 기초·광역 모두 개편 전후 각 변수에 동일하게 적용하며 단순회귀 기울기 값은 종전 1%p당 계수의 **100배**가 됩니다. 회귀선의 예측값·R²·p-값은 이 단위변환만으로 변하지 않습니다. X축과 관측치 표 및 CSV 내보내기는 **0~1 단위**입니다.

다중회귀 모형 (`statsmodels.OLS`, 절편 포함):

```text
자폐성 장애인 등록률(%) = β₀ + β₁ × 정규화 재정자립도(0~1) + β₂ × 합계출산율(명/여성) + ε
```

`Statistics/출산율/Birth rate.csv`는 KOSIS 스타일의 합계출산율(시도 합계 + 시군구 별 수치)로, 원본 2014~2022 기간을 `(연도, 광역, 기초)`로 결합합니다. 자폐성 장애 등록률은 **해당 지역 전체 주민등록인구** 대비 자폐성 장애 등록인원의 비율이며 전체 장애인 중 자폐성 구성비가 아닙니다. 다중회귀의 잔차·두 변수별 **실제 등록률 산점도**와 변수별 신뢰구간, 계수 p-값, 전체 F-검정 p-값, VIF까지 화면에서 확인할 수 있습니다. `site/data/multi_quality.json`에 지역 결합 내역/결측 목록을 보관하고 `site/raw/MULTI_*`에 statsmodels 텍스트 summary를 저장합니다.

**해석상 주의:** 동시기 합계출산율은 해당 연도의 자폐성 장애인 유병 원인을 나타내지 않습니다. 등록된 자폐성 장애인은 서로 다른 출생 연령 코호트를 포함하고, 연도 통합 모형은 지역 내 반복측정·고정효과를 통제하지 않습니다. 따라서 이 회귀는 탐색적 상관관계 분석이며 인과적 영향 추정이 아닙니다.

다중회귀의 출산율 지역 키 자체는 2,052/2,052개 모두 일치하지만, 2014년 경상북도 울릉군의 자폐성 장애인 등록인원은 원본 공란으로 해당 연도 Y값을 계산할 수 없어 회귀분석의 전체 유효 표본은 **2,051개**입니다. 결측 응답을 임의로 0으로 대체하지 않습니다.

## 신규 단순 OLS의 해석 주의

`site/data/birth_ols_models_*.json`과 `site/raw/BIRTH_OLS_*.txt`에 Python `statsmodels` 결과를 저장합니다. **합계출산율(독립변수)**은 같은 시점의 지역 출생 특성이며, **자폐성 장애 등록률(종속변수)**은 모든 연령을 포함합니다. 두 값 사이의 연관성은 등록·진단 환경과 인구구조·시간추세 등의 교란 요인에 영향을 받을 수 있고, 회귀계수가 출산율의 인과적 영향이라는 뜻은 아닙니다. 기초지자체별 9개년 통합/시계열 모형의 p-값은 군집상관을 보정하지 않습니다. 해당 페이지는 통계적 탐색 목적입니다.

## 장애유형을 확장한 분석의 해석

모형의 종속변수는 각 장애유형의 **장애등록인원 / 주민등록인구 × 100(%)**입니다. 전체 장애유형을 100%로 둔 **유형 구성비**가 아닙니다. 같은 연도의 합계출산율과 장애유형별 전체 연령층 등록률 사이의 연관성이며, 특정 장애가 해당 연도의 출산으로 발생했다는 뜻이 아닙니다. 특히 유형별 등록제도·진단 접근성·연령구성·이동 및 공통 시간추세를 통제하지 않고, 통합 모형에서는 지자체 반복관측도 고려하지 않으므로 유의한 회귀계수도 인과효과로 해석할 수 없습니다. 많은 유형·지역·연도를 반복적으로 검정하므로 **다중 검정으로 인한 우연한 유의성**에 주의하세요. 0~1 재정자립도 회귀계수의 변화폭은 X가 1.0만큼(100%p) 변하는 경우이며 1%p(0.01) 변화에 대한 기대 변화폭은 계수의 0.01배입니다.

`site/data/multi_quality.json`과 `site/data/birth_ols_quality.json`에 사용 가능한 관측치 수와 모델 수를 기록합니다. 조건을 만족하는 표본이 부족하거나 설계행렬이 특이행렬이면 0이 아니라 **추정 불가**로 표기합니다. 현재 GitHub Pages 구성은 정적 사이트이며, 분석은 `python build.py` 실행 중 statsmodels로 사전 계산됩니다.

  추정 불가 사유를 보여 줍니다. 광역 유형 등록률은 속한 기초지자체의
  모든 집계가 있을 때만 사용합니다.
- 2014~2017년 경기도 **청각·언어 통합 유형**은 청각/언어 개별 유형으로
  강제 분해하지 않습니다. 일부 조건에서 가능한 회귀도 전국 대표성을 뜻하지 않습니다.

모형 계산은 Python statsmodels OLS로 이루어지며 브라우저의 JavaScript는
미리 생성된 모형을 선택하고 그립니다. 모든 회귀는 탐색적 연관성일 뿐
인과효과를 뜻하지 않으며, 연도 통합 OLS는 반복관측·연도 고정효과를
통제하지 않습니다.


## 변수의 단위·환산·회귀계수 해석 (필독)

**모든 회귀는 (연도, 광역지자체, 기초지자체) 단위의 지역 관측자료를 이용합니다.**
단일 연도의 행정구역 간 회귀, 2014~2022년을 단순히 합친 통합 회귀,
개별 지자체의 연도별 회귀는 표본과 해석이 서로 다릅니다. 모든 통계는
같은 연도 값을 연결한 관측적 연관성이지 인과효과 추정이 아닙니다.

| 변수 | 화면·회귀에서의 단위 | 실제 계산식 / 출처 | β 계수 1단위 해석 |
|---|---|---|---|
| **Y: 장애인 등록률** | **%(백분율)** | `장애유형별 등록인원 ÷ 해당 연도 주민등록인구 × 100` | 종속변수 값 1은 **1%p**. `y=0.0006`은 **0.0006%**(인구 백만 명 중 6명)이지 0.06%가 아님. 원본 미보고 유형은 0 처리하지 않음 |
| 재정자립도(개편 전/후) | 비율 **0~1** | 원본 재정자립도(%) ÷ 100 | β는 비율 +1.00(=재정자립도 +100%p)에 대응. **재정자립도 +1%p(=0.01)일 때 예상 등록률 변화는 β×0.01%p** |
| 65세 이상 인구비율 | **%** | (`65~69`+`70~74`+`75~79`+`80~84`+`85세 이상`) ÷ 주민등록연앙인구 × 100 | X +1은 **인구구성비 +1%p**; 예상 등록률 변화는 β%p |
| 0~14세 인구비율 | **%** | (`0~4`+`5~9`+`10~14`) ÷ 주민등록연앙인구 × 100 | X +1은 **인구구성비 +1%p**; 예상 등록률 변화는 β%p |
| 합계출산율 | **명/여성 1명** | 같은 연도 해당 지역 합계출산율(연간, 기간지표) | X +1.0명/여성당 예상 등록률 변화는 β%p. **출생아 수/인구 100명이 아님** |
| 인구 1인당 진료비 | **만원/인/년** | 연간 전체 연령 **진료비 총액(천원) ÷ 주민등록연앙인구 ÷ 10** | X +1은 인구 1인당 연간 진료비 +**1만원**. β는 장애인 등록률의 예상 변화 **%p/만원** |
| **가구당 건강보험료** | **만원/세대/년** | 연간 총보험료(천원) ÷ **해당 연도 주민등록세대수** ÷ 10 | X +1은 지역의 연간 가구당 환산 보험료 +**1만원**. β는 등록률 **%p/(만원/세대/년)**. 월별·1인당 금액 아님 |

**단위 계산 예:** 연간 건강보험료 총액 `5,000,000천원`이고 해당 연도
주민등록세대수가 `20,000세대`라면 가구당 `5,000,000 ÷ 20,000 ÷ 10 = 25만원/세대/년`입니다.
월평균으로 단순 환산하려면 12로 나누지만, 이는 실제 월별 청구·납부액을
의미하지 않습니다. 가구당 보험료는 지역 **총보험료를 주민등록세대수로 나눈 환산값**이고,
건강보험 자격상 보험가입 세대별 실제 납부 보험료나 가구 소득의 직접 관측값이 아닙니다.
직장가입자 보험료 총액에는 사업주 부담액 등이 포함될 수 있습니다.

**진료비와 보험료는 다른 통계입니다.** 진료비는 해당 지역의 **연간 건강보험 진료비
집계액을 주민등록연앙인구**로 나눈 값이며, 환자가 직접 지불한 본인부담금이나
모든 비급여를 포함한 개인 지출액은 아닙니다. 건강보험료는 그 지역의
**연간 보험료 총액을 주민등록세대수**로 나눈 값입니다. 분모와 측정 대상이
다르므로 서로 같은 단위로 치환하거나 합산하면 안 됩니다.

**자료 결합·정합성:** 2014~2022년 `(연도, 시도, 시군구)`를 정규화해 결합합니다.
2014년 서울·인천·경기·강원 보험료 파일의 해당 연도 값은 `합계 = 직장 소계 + 지역 소계`,
`직장 소계 = 근로자 + 공·교` 검산이 맞지 않으므로 회귀에서 제외합니다. 보험료
원본 파일은 수정하지 않습니다. 제공된 **주민등록세대수 CSV를 원본 그대로 동봉**하여 가구당 보험료를 계산합니다.
세대수·보험료 자료의 누락 연도·지역에 대해서는 보간·추정 없이 그 관측치를 제외합니다. 건강보험 통합모형은 2015~2022년만 사용하며, 기존 5변수 선택기는 최종 화면에서 제거했습니다.

**OLS 출력의 단위와 진단:** `coef`는 각 X가 해당 표 단위로 1 증가할 때의 Y
예상 변화(%p), `std err`는 그 계수의 표준오차, `t`는 계수의 t통계량,
`P>|t|`는 양측 검정 p-값, `[0.025, 0.975]`는 95% 신뢰구간입니다.
`R-squared`(R²)는 모형의 적합도로 **인과효과 크기와 다릅니다**.
`Durbin-Watson`, `Omnibus`, `Jarque-Bera` 등은 잔차 진단입니다.
예측치 단위는 장애 등록률(%), 잔차는 실제값 − 예측값의 **%p**입니다.
OLS 계수와 일반 표준오차는 가정 의존적이며, 특히 9개년 단순 통합 OLS는
지자체별 반복측정, 연도효과, 의료서비스 접근성·연령구조 등의 교란을
별도로 보정하지 않습니다. 상관계수나 회귀계수만으로 원인·정책효과를 단정하지 마세요.

단위·원본 CSV 상세 내용은 [`Statistics/README.md`](Statistics/README.md),
웹사이트에서는 [`site/quality.html`](site/quality.html)의 **단위·환산 안내**에 정리했습니다.

## 최종 통합 연구 대시보드 (현재 기준)

**주요 연구 화면:** [최종 6변수 및 여섯 개별 단순회귀](site/unified.html?model=six).
이 화면이 현재 권장 분석 경로입니다. 구버전 5변수 선택기는 제거되었고,
기존 `age-medical-multi.html`, `age65-ols.html`, `under15-ols.html`,
`medical-ols.html`, `household-premium-ols.html`, `birth-ols.html` 주소는
각각 대응하는 통합 분석 탭으로 이동합니다. 기존 2변수 재정자립도·출산율
다중회귀는 별도 역사적 분석으로 보존하며 최종 6변수 모형과 혼동하지 않습니다.

### 연구 기간을 2014~2022년으로 정한 이유

- **2014년 시작:** 지방재정 재정자립도 세입과목 개편 시점이므로 이를 비교 연구의 시작점으로 설정했습니다.
- **2022년 종료:** 여러 지방자치단체에서 확보되는 장애 등록통계가 2022년에 종료되므로 공통 분석 기간의 끝으로 설정했습니다.
- **건강보험 포함 모형은 2015~2022년:** 2014년 진료비·건강보험료 데이터는 분석 적합성 문제가 있으므로 관련 **모든** 단순·다중 OLS, 통합기간, 시계열, 관측치, CSV에서 제외합니다. **원본 2014년 CSV는 보존**합니다.
- 2014년 건강보험과 무관한 재정자립도·출산율·인구구조 분석은 2014~2022년을 이용합니다.

### 현재 모델과 단위

`Y = β₀ + β₁X₁ + β₂X₂ + β₃X₃ + β₄X₄ + β₅X₅ + β₆X₆ + ε`

| 변수 | 정의 | 분모 / 단위 |
| --- | --- | --- |
| Y: 장애유형별 등록률 | 해당 유형 등록인원 ÷ 주민등록인구 × 100 | 해당 연도·지역 주민등록인구 / % |
| X₁: 재정자립도 | 세입과목 개편 전 또는 후 공식 비율 ÷ 100 | 원본 0~100%를 내부에서 0~1로 정규화 |
| X₂: 65세 이상 비율 | 65세 이상 주민등록연앙인구 ÷ 전체 주민등록연앙인구 × 100 | 주민등록연앙인구 / % |
| X₃: 0~14세 비율 | 0~14세 주민등록연앙인구 ÷ 전체 주민등록연앙인구 × 100 | 주민등록연앙인구 / % |
| X₄: 합계출산율 | 공식 합계출산율 | 명/여성 |
| X₅: 1인당 진료비 | 연간 총진료비(천원) ÷ 주민등록연앙인구 ÷ 10 | 주민등록연앙인구 / 만원/인/년 |
| X₆: 가구당 건강보험료 | 연간 총건강보험료(천원) ÷ 주민등록세대수 ÷ 10 | 주민등록세대수 / 만원/세대/년 |

위 여섯 X를 함께 사용하는 최종 다중회귀는 **2015~2022년**만 적합합니다.
각 X를 별도로 사용하는 여섯 단순회귀도 제공합니다.
재정자립도는 개편 전·후를 선택합니다. 모든 장애유형(전체 포함 17개)을
선택할 수 있고, 경기도 2014~2017년 `청각·언어` 통합 수치는
청각·언어에 임의 배분하지 않습니다. 결측은 0으로 대체하거나 보간하지 않습니다.

한 설명변수가 1단위 늘 때 β만큼 Y가 **퍼센트포인트(%p)** 변한다는 뜻입니다.
재정자립도 0~1 기준으로 0.01(원래 1%p) 증가 시는 0.01×β %p입니다.
단순회귀 계수는 통제변수가 없는 연관성이고, 다중회귀는 다른 다섯 변수를
동일하게 둔 조건부 연관성입니다. 계수 크기는 X의 단위가 달라 직접 비교하면
안 됩니다.

**건강보험료는 절대로 1인당 금액이 아닙니다.** 지역 보험료 총액을
실제 주민등록세대수로 나눈 연간 환산액이므로, 가구별 실제 고지 보험료의
단순평균과 동일하다고 단정할 수 없습니다. 진료비도 개인의 실제 본인부담금이나
모든 비급여 지출을 뜻하지 않습니다.

### Python 실행·정적 배포

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python build.py
```

`python build.py`가 분석 결과와 전체 정적 사이트를 `site/`에 재생성합니다.
`site/data/unified_manifest.json`은 변수·기간 정의를,
`site/data/unified_index_<모형>.json`은 전체 유형·지역·연도별 경량 통계표를,
`site/data/unified_detail/<모형>/<유형번호>/<시점>.json`은 실제
statsmodels OLS 원문·완전관측치·예측값·잔차를 담습니다.
해당 모델은 일치하는 경량 인덱스와 상세 JSON에서 한 번만 적합됩니다.
구식 5변수 JSON은 빌드 결과에서 제거합니다.

Python 분석은 원본 CSV, 설치된 NumPy와 statsmodels만으로 동작하므로
해당 패키지가 이미 설치된 오프라인 환경에서도 재현할 수 있습니다.
프런트엔드 차트는 Chart.js CDN을 사용하므로 오프라인에서는 차트 로드가
되지 않을 수 있습니다. 그러나 통계·관측치·CSV 표시는 로컬 정적 JSON을
통해 조회 가능합니다. 완전한 오프라인 차트 사용을 원한다면
Chart.js 라이브러리를 로컬에 공급해야 합니다.

### 검증과 해석의 한계

모든 분석은 `statsmodels.OLS(...).fit().summary()`를 원문으로 저장하며
R²/수정 R²·절편·모형 F검정 p값·계수와 p값·95% 신뢰구간·표본 수를
분리합니다. 다중회귀 여섯 개 실제 등록률 산점도와 나머지 변수 평균 고정
조건부 예측선을 구분하고, 계수·절편·R²·수정 R²·기울기 p값·전체 F검정
p값의 연도별 추이를 보간 없이 제공합니다.

OLS는 **인과효과의 증거가 아닙니다**. 지역별 인구구조, 재정자립도,
진료비, 건강보험료에는 상관 및 다중공선성이 있을 수 있고 건강비용은
고령화·질병 부담의 결과일 수도 있습니다. 연도 통합 OLS는 지자체
반복관측이나 연도효과를 별도로 통제하지 않습니다. 결측, 행정구역 개편,
출처 간 집계 기준 차이가 유효 표본 수를 바꿉니다. 추정 불가한 조합은
표본 부족·공선성·결측에 따른 원문 사유를 표시합니다.
