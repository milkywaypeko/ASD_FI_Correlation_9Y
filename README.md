## 최종 6변수 회귀모형

**종속변수(Y):** 선택한 장애유형 등록률(%).

```text
Y = β₀ + β₁·X₁ + β₂·X₂ + β₃·X₃ + β₄·X₄ + β₅·X₅ + β₆·X₆ + ε
```

| 변수 | 계산식 / 의미 | 회귀 단위 |
| --- | --- | --- |
| Y 장애유형별 등록률 | 해당 유형 등록인원 ÷ 해당 연도·지역 주민등록인구 × 100 | % |
| X₁ 재정자립도 | 개편 전/후 선택. 원본 0–100%이면 내부에서 ÷ 100 | 0–1 |
| X₂ 65세 이상 비율 | 65세 이상 주민등록연앙인구 ÷ 전체 주민등록연앙인구 × 100 | % |
| X₃ 0–14세 비율 | 0–14세 주민등록연앙인구 ÷ 전체 주민등록연앙인구 × 100 | % |
| X₄ 합계출산율 | 지역별 공식 합계출산율 | 명/여성 |
| X₅ 1인당 진료비 | 연간 지역 총진료비(천원) ÷ 주민등록연앙인구 ÷ 10 | **만원/인/년** |
| X₆ 가구당 건강보험료 | 연간 지역 총보험료(천원) ÷ 주민등록세대수 ÷ 10 | **만원/세대/년** |

모든 X를 사용하는 최종 다중회귀는 **2015–2022년**에 한정합니다. 재정자립도는 개편 전·후 중 하나만 사용하고, 다른 변수의 정의는 바꾸지 않습니다.

**분모를 혼동하지 마세요.** 진료비는 해당 지역의 연간 총진료비를 연앙인구로 나눈 환산치로, 실제 개인 본인부담액이나 모든 비급여를 포함한 의료비가 아닙니다. 건강보험료는 **절대 1인당 금액이 아닙니다.** 지역 총보험료를 주민등록세대수로 나눈 **세대당 연간 환산액**이며 개별 가구에 실제 고지된 금액의 단순평균이라고 단정하지 않습니다.

### 장애유형 및 결측

선택 가능한 17종: **전체, 지체, 뇌병변, 시각, 청각, 언어, 청각·언어, 지적, 자폐성, 정신, 신장, 심장, 호흡기, 간, 안면, 장루·요루, 뇌전증**.

경기도 2014–2017년의 **청각·언어 통합 집계**는 별도 유형으로 보존하고 청각/언어에 임의로 분배하지 않습니다. 원본의 공란·누락·불일치 값은 **0으로 대체하거나 보간하지 않습니다.** 모델마다 종속변수와 필요한 설명변수가 모두 있는 완전관측치만 사용합니다. 추정할 수 없는 경우 표본 부족·공선성·결측 등 사유를 표시합니다.

## 화면의 통계와 해석

- 독립변수별 **기울기 β**, 절편 β₀, **R²와 수정 R² 각각**, OLS 계수의 p값 및 95% 신뢰구간, 모형 F검정 p값, 표본 수 n. **단순회귀에서만** 기울기 β₁과 SciPy 피어슨 상관계수 r·양측 p값·95% 신뢰구간을 별도 표시
- 최종 6변수 모형의 **6개 실제 등록률 산점도**. 각 주황색 선은 나머지 다섯 설명변수를 현재 표본 평균으로 고정한 **다중회귀 조건부 예측선**입니다. 단순회귀선이 아닙니다.
- 연도별 기울기, 절편, R², 수정 R², 설명변수 p값, 모형 F검정 p값 추이. **단순회귀에서만 X–Y 피어슨 r 추이**를 추가합니다. 결측 연도는 보간하지 않습니다.
- **04 / COMPLETE REGRESSION INDEX**에서 연도·지역·장애유형 검색, 분석 단위 선택, 정렬, 페이지 이동, 검색 결과 CSV 다운로드
- **Raw·관측치**에서 실제 `statsmodels.OLS(...).fit().summary()` 전체 출력, **단순회귀에 한해** SciPy `PearsonRResult`·`ConfidenceInterval` 원시 반환값과 X·Y 실제 관측 쌍, 예측값, 잔차 및 별도 관측치 CSV 다운로드

설명변수가 **1 분석 단위** 증가할 때의 회귀계수 β는 등록률의 예상 변화량을 **퍼센트포인트(%p)**로 표시합니다. 단순회귀는 다른 변수를 통제하지 않고, 다중회귀는 나머지 설명변수를 고정한 조건부 연관성입니다. X의 단위가 서로 다르므로 계수 크기를 직접 비교하면 안 됩니다. 재정자립도는 0–1로 정규화하므로 **원래 1%p 증가 = X₁ 0.01 증가**입니다.

이 분석의 한계에는 지자체 반복관측·연도효과를 따로 통제하지 않은 통합 OLS, 다중공선성, 행정구역 개편, 집계 기준 차이, 결측에 따른 n 변화가 포함됩니다. 진료비·보험료는 지역의 고령화나 질병 부담의 *결과*일 수도 있으며 인과적 효과로 해석할 수 없습니다.

### 피어슨 상관계수 r의 정의와 해석

개별 **단순회귀 화면에서만**, 선택한 장애유형의 등록률 Y(%)와 설명변수 X 사이의 **피어슨 적률상관계수 r**을 제공합니다. 상단 카드에 **기울기 β₁, 피어슨 r, OLS 기울기 β₁의 양측 p값을 각각** 표시합니다. 매우 작은 p값은 0으로 반올림하지 않고 `2.30e-10` 같은 지수 표기법을 사용합니다. 계산 결과 자체가 0으로 저장된 경우에는 정밀도 한계 가능성을 함께 알립니다. **최종 6변수 다중회귀 화면에서는 상관계수 카드·열·추이·SciPy Raw를 표시하지 않고**, 6개 설명변수의 β·OLS p값·95% 신뢰구간과 모형의 R² 등만 제공합니다. r은 다른 설명변수를 통제한 편상관이 아니므로 다중회귀 결과에 혼재시키지 않습니다.

```text
r(X,Y) = Σ[(Xi − X̄)(Yi − Ȳ)] / √(Σ(Xi − X̄)² · Σ(Yi − Ȳ)²)
```

- 범위는 **−1에서 +1**입니다. 부호는 선형관계의 방향, 절댓값은 이변량 선형관계의 크기를 뜻하며 인과관계를 증명하지 않습니다.
- **실제 계산 라이브러리:** `scipy.stats.pearsonr(x, y, alternative="two-sided")`를 사용합니다. SciPy가 반환하는 `statistic`(r), `pvalue`, `confidence_interval(confidence_level=0.95)`(Fisher 변환 기반), SciPy 버전과 원시 객체 표현을 동일한 상세 JSON에 보존합니다. SciPy는 `requirements.txt`에 명시하며, 회귀계수·R²·OLS p값은 기존 `statsmodels`가 계속 계산합니다.
- **SciPy r의 양측 p값과 OLS 기울기의 p값은 다른 항목**으로 단순회귀 화면에서 구분합니다. 다중회귀는 SciPy 상관통계량을 화면과 다운로드 CSV에 노출하지 않으며 OLS 계수 검정만 표시합니다.
- **원시 분석 확인:** 개별 단순회귀 비교표에서 `Raw·관측치`를 클릭한 다음 `SciPy Raw 결과 및 실제 X·Y 관측자료`에서 변수를 선택하면 반환 객체·양측 p값·95% 신뢰구간·상수열/표본 부족 경고 및 관측 X·Y 쌍을 볼 수 있으며, 모든 쌍을 CSV로 저장할 수 있습니다.
- **모델별 동일한 완전관측치**에서 계산합니다. 단순회귀의 r은 해당 X와 Y가 존재하는 표본에서 계산합니다. 6변수 다중회귀는 독립된 OLS 모형의 완전관측치 규칙을 유지하지만 상관계수는 화면에서 표시하지 않습니다.
- 지역·장애유형·분석 기간·재정자립도 개편 전후를 변경하면 해당 모형의 r도 바뀝니다. 단순회귀의 β₁과 r은 상단 개별 카드에 표시하며 r은 계수표, 전체 회귀 비교표, 연도별 추이, CSV, SciPy Raw·관측치 상세에만 함께 반영됩니다.
- 완전관측치가 **2개 미만**이거나 X 또는 Y가 상수이면 r을 계산하지 않고 **결측(— / JSON null)** 으로 표시합니다. 해당 상태를 0으로 대체하지 않습니다. 작은 표본에서 SciPy가 95% 신뢰구간을 반환하지 못하거나 경고를 내면 그 결과·사유도 원문에 남깁니다.
- 연도 통합 r은 지역 반복관측 및 연도효과를 통제하지 않는 **비가중 지역 수준 상관**입니다. 단순회귀에서 절편을 포함하고 정상 추정되면 이론상 **R² = r²**이나, 다중회귀에서는 설명변수 6개 각각의 회귀계수를 표시하며, 별도의 피어슨 r을 표시하지 않습니다.

## 재현 실행

Python과 `requirements.txt`에 명시된 라이브러리가 준비된 환경에서:

```bash
python -m pip install -r requirements.txt
python -m pip install pytest  # 테스트용 도구(분석 필수 의존성에는 포함되지 않음)
python -m pytest tests -q
python build.py
python -m http.server 8000
```

- [`http://localhost:8000/`](http://localhost:8000/) — **최종 6변수 통합 화면** (`index.html`).
- [`http://localhost:8000/site/index.html`](http://localhost:8000/site/index.html) — 기존 **데이터 탐색** 화면.
- [`http://localhost:8000/site/unified.html?model=six`](http://localhost:8000/site/unified.html?model=six) — 통합 화면 직접 주소.

`python build.py`는 통계 결과와 정적 웹사이트를 재생성하며, `site/unified.html`을 기반으로 **프로젝트 최상위 `index.html`을 다시 생성**합니다. 이때 `<base href="./site/">`를 넣어 리소스 경로를 맞춥니다. `site/index.html`은 데이터 탐색 화면으로 **변경하지 않고 보존**합니다. **따라서 최상위 `index.html`만 수동 수정해도 다음 빌드에서 덮어쓰므로 빌드 규칙도 함께 관리해야 합니다.**

```text
build.py                   전체 분석 + 정적 사이트 생성
build.py       인구·진료비 및 기존 분석
build.py      보험료 정합성·세대수 결합
build.py        최종 6변수 및 6개 단순회귀 JSON 생성
site/unified.html          통합 분석 화면
site/index.html            기존 데이터 탐색 화면
site/assets/js/sidebar.js  공통 사이드바
site/data/unified_manifest.json
site/data/unified_index_<모형>.json.gz
site/data/unified_detail/<모형>/<장애유형번호>.json.gz
index.html                 GitHub Pages 루트 (빌드 산출물)
tests/                     기존·추가 분석 및 화면 계약 테스트
```

통합 화면은 경량 인덱스를 먼저 읽고 상세 OLS JSON은 선택 시에만 가져옵니다. `*.json.gz`는 브라우저의 `DecompressionStream('gzip')`으로 해제합니다. Python에 설치된 필수 패키지와 원본 CSV가 있으면 분석 계산은 인터넷 없이도 가능하지만, 차트는 외부 **Chart.js CDN**을 사용하므로 오프라인에서 별도 차트 라이브러리 제공이 필요합니다.

## GitHub Pages 배포와 검증

이 프로젝트는 정적 GitHub Pages 사이트입니다. 저장소의 **`main` 브랜치 / `/(root)`** 를 배포 소스로 사용하고 `.nojekyll`을 유지합니다. 배포 주소는 [https://milkywaypeko.github.io/ASD_FI_Correlation_9Y/](https://milkywaypeko.github.io/ASD_FI_Correlation_9Y/) 입니다.

분석 코드·페이지를 바꾼 후에는 테스트 → `python build.py` → 생성 JSON 일치 검증 → PR 병합 → Pages 배포 작업 성공 확인 순서로 진행합니다. `site/data/`의 원문·관측치가 포함된 gzip 자료는 정적 배포 파일 수를 줄이기 위해 모형 및 유형별로 묶으며, **압축 자체는 통계값을 바꾸지 않습니다.** 과거 배포에서 대량 파일의 `syncing_files` 시간 초과가 있어 압축을 도입했습니다.

**연구 해석에 관한 주의:** 본 저장소의 회귀 결과는 기술적·탐색적 연관성 분석입니다. 인과추론 또는 정책효과 추정으로 오해하지 마세요.

장애인 등록인원 원본 17개는 [이전 연구 `milkywaypeko/ASD_FI_Correlation`](https://github.com/milkywaypeko/ASD_FI_Correlation)에서 사용한 **각 시도 「○○기본통계」 장애인 등록 표와 같은 KOSIS 표를 연도 범위만 달리하여 다시 추출**한 자료입니다. 기존 연구의 README에는 17개 시도의 KOSIS `orgId`/`tblId` 직접 링크와 2023.04.20 출처 기록이 남아 있습니다. 이번 연구는 원표의 2014–2022년 열을 사용합니다. 이는 옛 단일 연도 CSV를 그대로 복사했다는 뜻이 아니며, 통계표의 범위와 집계 기준은 지역별로 다를 수 있습니다. 정확한 17개 직접 인용 링크는 [KOSIS_SOURCES.md](KOSIS_SOURCES.md#시도별-장애인등록-kosis-원표-17개--이전-연구에서-이어진-자료-계보)에 정리했습니다.



### 단일 Python 빌드 진입점

정적 사이트 생성과 전체 통계 계산은 **`python build.py`** 한 파일로 실행합니다. 인구·의료비·보험료 전처리, 단순/다중 OLS, SciPy 상관분석, 통합 JSON 및 GitHub Pages 출력까지 `build.py`에 통합했습니다. 별도 분석용 Python 모듈은 필요하지 않습니다. 테스트는 `python -m pytest tests -q`로 실행합니다.


### 빌드 성능 최적화

GitHub Actions는 화면/번역/문서/테스트만 변경되면 전체 OLS 재계산을 건너뛰고 빠른 pytest 및 JavaScript 검사를 실행합니다. `build.py`, `requirements.txt`, `Statistics/` 원본 자료 또는 빌드 워크플로가 변경되면 **전체 통계 재생성 및 결과 검증**을 수행합니다. 수동 워크플로 실행도 항상 전체 재생성합니다. 이 최적화는 **PR 검증 시간**을 줄이며, GitHub Pages 배포 방식은 변경하지 않습니다.

전체 빌드에서는 통합 회귀의 연도·광역별 입력을 미리 그룹화해 중복 필터링을 줄이고, 기존 분석/통합 분석 및 모델별 소요 시간을 출력합니다. OLS, SciPy 검정, 신뢰구간, 원본 관측치와 출력 형식은 유지됩니다. 실제 단축 시간은 GitHub Actions 로그에서 비교해야 합니다.


### 중복 통계 생성 코드 정리

현재 사용하는 장애유형별 단순회귀 및 6변수 다중회귀의 상세 결과는 통합 분석 생성기 `build_unified_analysis()`에서 생성합니다. 예전에 별도 장애유형별 모델 파일을 만들던 미사용 `_emit_disability_type_models()` 함수는 제거했습니다. 기존 개별 분석 화면이 참조하는 연도별·지역별 파일 생성기는 화면 호환성을 위해 유지합니다. 기존 분석 페이지를 통합 결과로 전환하기 전에는 해당 생성기를 삭제하지 않습니다.
