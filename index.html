진료비는 개인의 실제 본인부담액이나 모든 비급여를 포함한 의료비가 아닙니다. 가구당 건강보험료는 지역 총보험료를 주민등록세대수로 나눈 환산치이지, 가구별 고지액의 단순평균이 아닙니다. 건강보험료는 1인당으로 환산하지 않습니다.

피어슨 r, 양측 p값, Fisher 변환 기반 95% 신뢰구간은 Python SciPy의 scipy.stats.pearsonr로 계산하며 원시 결과와 실제 X·Y 표본을 상세보기에서 확인할 수 있습니다. 표본 3개 이하에서는 신뢰구간이 극단적이거나 계산 불가능할 수 있습니다.

피어슨 상관계수 r은 −1~+1의 값으로 이변량 선형관계의 방향과 크기를 나타냅니다. r은 회귀계수 β나 R²와 다르고, 다중회귀에서는 다른 설명변수를 통제하지 않는 단순 상관입니다. 사용 표본이 2개 미만이거나 X 또는 Y가 상수이면 계산하지 않고 결측(—)으로 표시합니다. r이나 R²는 인과관계의 증거가 아닙니다.

지역 단위 OLS는 통계적 연관성이지 인과관계가 아닙니다. 단순회귀 계수는 통제변수 없이 X의 1단위 증가와 연결된 등록률 변화(%p)를, 6변수 다중회귀 계수는 다른 다섯 X를 고정할 때의 변화(%p)를 뜻합니다. 서로 다른 단위의 계수 크기를 직접 비교하지 마세요. 인구구조·진료비·보험료·재정자립도 사이의 다중공선성, 건강비용과 지역의 질병부담 간 역방향 관계, 연도 통합 OLS의 지자체 반복관측·연도효과 미통제, 결측·행정구역 개편·집계 기준 차이 및 표본 수 변화를 고려해야 합니다.

경기도 2014~2017년의 「청각·언어」 통합 등록인원은 청각·언어 각 유형에 임의 배분하거나 결측을 0으로 채우지 않습니다. 모든 불가한 회귀는 추정 실패 이유를 표시합니다. 품질 감사 · 연구 README

KOSIS 통계 출처·재현성 점검

이 연구의 원본 CSV는 모두 KOSIS 국가통계포털에서 취득한 통계입니다. 작성기관은 행정안전부(주민등록·재정), 각 시도별 기본통계 작성기관(장애인 등록통계), 국가데이터처(출산율), 국민건강보험공단(진료비·보험료) 등으로 구분합니다. 장애인 원본 17개는 이전 ASD_FI_Correlation 연구에 사용한 같은 KOSIS 표에서 연도 범위만 2014–2022년으로 바꿔 추출한 자료입니다. 상세 표 ID를 확인하지 못한 경우는 임의 출처를 만들지 않습니다. 출처 정보 열람일은 2026.11.08이며 실제 CSV 다운로드 날짜와 구분됩니다.
