01 / DEFINITION

장애인 비율의 분모·분자

장애유형별 등록률 = (해당 장애유형 등록인원 ÷ 해당 연도 주민등록인구) × 100 입니다. 전체 등록률은 상호 배타적인 장애유형 인원을 합산하여 같은 분모로 나눕니다. 다만 일부 드문 장애유형의 원본 수치가 비어 있는 지역·연도는 제공된 수치만 합산했으므로 전체 등록률이 실제보다 조금 낮을 수 있습니다. 자세한 지역 목록은 아래 품질 검사표에서 확인할 수 있습니다. 연도는 2014~2022년이며, 시도별 장애인 자료에 표시된 각 연도 수치를 그대로 사용합니다.

재정자립도는 원본의 세입과목 개편 전 및 세입과목 개편 후 통계를 별도 변수로 유지하되, 원본 CSV를 건드리지 않고 빌드 시 100으로 나눠 0~1 범위의 재정자립도로 변환합니다. 광역 분석은 각 광역지자체의 공식 '소계' 재정자립도를 사용하며 기초지자체의 값을 산술평균하지 않습니다.

02 / TERRITORIAL JOIN

지역명 정규화와 예외 처리

강원도 → 강원특별자치도, 전라북도 → 전북특별자치도, 인천 남구 → 미추홀구로 같은 행정단위를 연결합니다. 재정자료의 ‘충북 청주시’, ‘충북 청원군’, ‘경기 여주군’ 등도 표준 지자체명으로 정리합니다. 2014년 청주시는 통합 청주시 인구·장애등록인원을 사용하며, 재정자료의 ‘충북 청주시’와 연결합니다. 같은 연도 재정자료에 남아 있는 청원군은 장애·인구 자료가 없어 관측치에 포함하지 않습니다. 2023년 군위군 소속 시도 변경은 이 분석 기간 밖이므로 2014~2022년 경상북도로 취급합니다.

세종특별자치시 및 제주특별자치도는 사용자 지정 방식에 따라 각각 광역 1개 = 기초 1개 단위로 취급합니다. 두 지역은 원본 장애유형별 합계가 제공되므로 기초 1개 관측치로 넣되, 실제 행정계층과 동일하다고 해석하지 않아야 합니다.

경기도의 2014~2017년 ‘청각·언어’ 통합 통계는 청각·언어를 억지로 분리하지 않고 독립된 유형으로 표시합니다. 2018년부터 ‘청각’, ‘언어’ 각각의 시계열에는 과거 통합치를 추가하지 않습니다. ‘장루요루/장루, 요루/장루·요루’와 ‘지체장애/지체’ 등은 통일합니다.

03 / REGRESSION

OLS 결과 해석

종속변수 Y는 장애인 등록률(%), 독립변수 X는 재정자립도(0~1)이며, 절편이 있는 최소제곱 직선 Y = β₀ + β₁X + ε을 statsmodels.api.OLS로 적합합니다. p-값은 기울기 0에 대한 양측 검정의 p-값입니다. 결측치를 제외한 표본이 3개 미만이거나 X가 상수이면 계수를 계산하지 않습니다.

특정 연도를 선택하면 그 연도의 지자체 간 횡단면 회귀를, 전체 시점 통합은 연도별 관측치를 모아 단순 OLS를 수행합니다. 기초지자체 시계열 모드는 해당 지자체의 9개 연도 관측치로 별도 회귀합니다. 단순 통합 OLS는 시점 간 반복 측정, 시간 추세 및 교란변수를 통제하지 않으므로 인과효과나 정책 효과를 의미하지 않습니다.

04 / ALL DISABILITY TYPES · MULTIVARIATE

장애유형별 등록률과 합계출산율

확장된 장애유형별 다중선형회귀 페이지는 종속변수를 사용자가 선택한 장애유형 등록률(인구 대비 %), 독립변수를 재정자립도(빌드 시 정규화한 0~1 값)와 지역의 합계출산율(여성 1인당 명)로 설정합니다. 각 연도와 지자체를 정확히 연결하며, 세종·제주는 공식 광역 합계출산율을 사용합니다. 결측치는 0으로 채우지 않습니다. 출산율과 장애 등록률의 시계열 간 시간차를 고려하지 않은 동시기 다중 OLS 결과는 인과관계를 의미하지 않습니다. 연도 통합모형은 반복측정/연도 및 지역 고정효과를 통제하지 않으므로 p-값을 신중히 해석해야 합니다.

05 / ALL DISABILITY TYPES · SIMPLE OLS

출산율 × 장애유형별 등록률 단순회귀

출산율 단순 OLS 페이지에서는 재정자립도를 회귀에 포함하지 않고, Y(%) = β₀ + β₁ × 합계출산율(명/여성) + ε만 추정합니다. 2014~2022년 연도별/전체기간/광역별/개별 기초지자체 시계열의 회귀계수·p-값과 statsmodels 원문을 제공합니다. X 또는 Y가 결측인 관측치는 해당 모델에서 제외하며, 각 유형의 원본 결측은 0으로 간주하지 않으며, 경기도 2014~2017 청각·언어 통합항목은 두 분리 유형으로 복제하지 않습니다. 출산율은 해당 연도 출산 특성이고 등록 장애인은 여러 출생 연령대를 포함하므로 회귀 결과는 동시기 지역 간 연관성이지 출산율이 특정 장애유형에 미치는 인과효과가 아닙니다.

06 / FISCAL INDEPENDENCE VS FERTILITY

재정자립도와 합계출산율 단순회귀

재정자립도 × 출산율 OLS 페이지는 Y(합계출산율, 명/여성) = β₀ + β₁ × X(재정자립도, 0~1) + ε 모형을 분석합니다. 세입과목 개편 전/후를 구분하며 재정자립도는 원본 0~100 값의 100분의 1로 빌드할 때만 변환합니다. 결측값은 0으로 대체하지 않습니다. 연도별 횡단면, 9개년 통합, 광역지자체 비교, 개별 기초지자체 9개년 시계열을 제공합니다. 기울기는 재정자립도 1.0 변화당 출산율 변화이므로 재정자립도 0.1 변화의 효과를 볼 때는 0.1을 곱합니다. 지역적 관측 상관관계이며 인과효과는 아닙니다. 통합 모형은 지역·연도 고정효과를 통제하지 않습니다.

CORRELATION / PEARSON r

장애인 등록률과 설명변수의 피어슨 상관계수

개별 단순회귀 화면에서 SciPy scipy.stats.pearsonr(X, Y, alternative="two-sided")로 피어슨 상관계수 r과 양측 p값을 계산합니다. SciPy 결과 객체의 confidence_interval(confidence_level=0.95)로 95% 신뢰구간도 생성하고, 원래 반환 객체의 표현과 경고·표본 수·라이브러리 버전을 저장합니다. 종속변수인 장애유형별 등록률(%)과 각 설명변수 사이의 선형 상관을 계산하며, 각 모형에 사용한 동일 완전관측치만 사용합니다. 최종 6변수 다중회귀 화면에서는 r·SciPy p값·신뢰구간을 노출하지 않고, 여섯 설명변수의 조건부 회귀계수 β와 OLS 검정 결과를 표시합니다. 단순회귀에서는 기울기 β₁과 피어슨 r을 상단 별도 통계 카드로 표시합니다. 건강보험료/진료비가 들어간 모형은 2015~2022년만 사용합니다.

r = Σ[(Xi−평균X)(Yi−평균Y)] / √(Σ(Xi−평균X)² × Σ(Yi−평균Y)²)이며 범위는 −1~+1입니다. 값이 0이면 선형관계가 관측되지 않는다는 의미이지 관계나 인과관계가 없다는 증명은 아닙니다. 표본 2개 미만, X 또는 Y 상수열 등 계산이 불가능한 경우는 **결측(null)**으로 저장하고 0으로 치환하지 않습니다. 단순회귀(절편 포함)에서 정상적인 경우 R² = r²이지만 6변수 모형의 R²는 개별 r²와 다릅니다.

OLS 계수의 p값·신뢰구간은 statsmodels에서, SciPy 상관계수의 p값·신뢰구간은 SciPy에서 별도로 계산합니다. 개별 단순회귀의 Raw·관측치 상세보기에는 실제 PearsonRResult(statistic, pvalue), ConfidenceInterval(low, high), 표본 수 n, 경고·계산 실패 사유와 함께 회귀에 사용한 실제 X·Y 쌍을 제공하고 CSV로 저장합니다. 이는 요약된 OLS 표가 아니라 SciPy 반환값을 보존한 자료입니다.

단순회귀의 r은 상단 카드, 회귀 인덱스, Raw·관측치, 연도별 추이 및 CSV에 표시합니다. 6변수 다중회귀 화면과 CSV에는 포함하지 않습니다. 연도 통합 상관은 비가중 지역별 관측치의 연관성이며, 지역 반복관측·연도효과·교란요인을 따로 통제하지 않으므로 인과효과로 해석해서는 안 됩니다.

보험료 포함 모형의 자료 가용성: Statistics/인구/행정구역(시군구)별 주민등록세대수.csv는 실제 원본 자료로 포함됐으며 연도·지역별 가구당 보험료를 계산합니다. 다만 세대수·보험료 결측 시 해당 관측치는 제외합니다. 2014년 건강보험료·진료비는 전국 모든 지역에서 해당 회귀분석에 사용하지 않고 2015~2022년으로 제한합니다. 최종 5변수 모형은 제공하지 않고, 6변수 다중회귀 및 여섯 개별 단순회귀를 제공합니다.

OLS의 coef는 X 1단위 증가당 Y의 예상 변화(%p), std err는 표준오차, P>|t|는 양측 검정 p-값입니다. R-squared는 설명력이며 인과효과가 아닙니다. 전체 기간 통합은 지역별 반복 관측·연도효과를 보정하지 않습니다. 자료 품질 페이지의 단위 안내도 참고하세요.

장애인 등록통계 출처 계보: 기존 ASD_FI_Correlation 연구의 17개 시도별 「기본통계」 KOSIS 통계표를 사용하되 이번에는 연구기간 2014–2022년의 연도 열을 취득했습니다. 기존 연구가 기록한 2023.04.20 출처 시점과 이번 출처 검토일 2026.11.08을 구별합니다. 개별 표의 정확한 원 URL은 기존 연구 출처 링크에 있습니다.

재현 순서는 python -m pip install -r requirements.txt, python build.py, python -m pytest tests -q입니다(테스트 러너 pytest 별도 설치). 기존 계수·원자료·원문은 빌드로 생성하며, 외부 CDN Chart.js가 없어도 Python 분석 자체는 로컬에서 재현됩니다. 통계의 인과해석 금지, 지자체 반복관측과 연도효과 미통제, 원자료 결측 및 집계기준 차이에 유의합니다. 전체 출처 인용문 및 안전한 삭제 안내는 저장소 최상위 KOSIS_SOURCES.md와 REPRODUCIBILITY.md에 기록했습니다.
